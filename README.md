## ✨ Features

- **Zero dependencies** — pure HTML, CSS, and vanilla JavaScript
- **Three complete HCM simulations** — each with unique UI and functionality
- **Instant platform switching** — navigate between systems seamlessly
- **Live data interaction** — add employees, payroll entries, and records dynamically
- **Responsive design** — works across desktop, tablet, and mobile
- **Realistic enterprise workflows** — based on actual HCM platforms
- **Dashboard analytics** — HR metrics, payroll insights, and workforce trends
- **Modular architecture** — separate sections for each platform

---

## 🗂️ Core Modules

Each platform includes the following modules:

```
├── 🏠  Hero Section          — Platform overview & navigation
├── 📊  Dashboard             — KPIs and workforce insights
├── 👤  Employee Management   — Employee records and data
├── 🕒  Attendance & Leave    — Time tracking and leave management
├── 💰  Payroll               — Salary, deductions, and payslips
├── 📈  Performance           — Reviews and goal tracking
├── 🎯  Recruitment           — Hiring pipeline and candidates
└── 📊  Reports & Analytics   — HR insights and reporting
```

## 🚀 Getting Started

No installation required.

```bash
# Clone the repository
git clone https://github.com/your-username/hcm-arena.git

# Navigate into the folder
cd hcm-arena

# Open the file
open index.html
```

Or simply double-click the HTML file to open in your browser.

## 🛠️ How It Works

- Each platform is wrapped in its own container
- JavaScript controls visibility and navigation
- Platform switching toggles active views dynamically
- All interactions are handled using scoped vanilla JavaScript
